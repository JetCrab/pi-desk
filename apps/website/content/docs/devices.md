在手机、平板或另一台电脑上打开 Pi Desk，继续查看消息和执行任务。项目仍在运行 Pi Desk 的电脑上，访问设备只需要浏览器。

公网访问只需一台已安装 Docker 的 Linux 公网服务器。按下面的步骤设置密码、启动隧道并连接桌面端，即可通过服务器 IP 访问。

## 设置访问密码

在运行 Pi Desk 的电脑上，进入「设置 → 登录保护」，设置至少 8 位密码并启用。**远程访问必须先设置密码，并保持登录保护开启。**

访问密码用于登录 Pi Desk；后面用到的连接密钥用于桌面端连接隧道，两者不同。

## 启动 Docker

以下统一使用示例 IP `203.0.113.10`，请替换成自己的服务器公网 IP；将 `<隧道镜像>` 替换为发布的镜像地址，然后在服务器运行：

```bash
docker run -d --name pi-desk-tunnel \
  --restart=always \
  --network=host \
  --log-opt max-size=10m --log-opt max-file=3 \
  -v /home/apps/pi-desk-tunnel/data:/data \
  -e TZ=Asia/Shanghai \
  -e PI_DESK_TUNNEL_PUBLIC_HOST=203.0.113.10 \
  '<隧道镜像>:latest'
```

首次启动会自动生成并保存密钥。打开服务器上的 `/home/apps/pi-desk-tunnel/data/connection.txt`，取得下一步需要的控制服务地址和连接密钥；重启容器会沿用这些信息。

## 开放服务器端口

在云服务器安全组和服务器防火墙中放行以下 **TCP** 端口：

- `7001`、`7002`：桌面端连接隧道使用。
- `40333`：其他设备访问 Pi Desk 使用。修改公网端口后，放行对应的新端口。

## 配置桌面端

1. 打开 Pi Desk 桌面端，先启动本机服务，确认本机网址能打开。默认网址是 `http://127.0.0.1:30333/`。
2. 在「控制中心 → 隧道连接」填写控制服务地址 `http://203.0.113.10:7001`，将刚取得的连接密钥填入「控制密钥」，然后保存。
3. 编辑本机网址，在高级设置的「公网端口」中勾选「配置公网 TCP 转发」，填写 `40333` 并保存。
4. 返回控制中心，启动该网址的公网端口，等待显示已连接。

多个本机网址需要使用不同的公网端口，并分别在服务器放行。

## 在其他设备打开

在另一台设备的浏览器或 Android 客户端填写 `http://203.0.113.10:40333/`，输入之前设置的访问密码即可使用。发送一条消息并确认回复实时出现，就完成了连接。

- **消息同步**：访问同一个 Pi Desk 时，会话、已发送消息和结果会同步；未发送草稿各自保留。
- **保持在线**：运行 Pi Desk 的电脑、桌面端和隧道容器需要持续运行；从托盘退出桌面端会中断远程访问。
- **传输方式**：IP 直连使用 HTTP，浏览器到服务器这一段不加密；需要加密时可额外配置 HTTPS，不影响上述隧道配置。

## 同一局域网访问

两台设备在同一个局域网时，可以不用公网服务器和隧道。先设置访问密码，再让 Pi Desk 监听局域网地址，例如：

```bash
pi-desk start -H 0.0.0.0 -p 6233 --no-open
```

在电脑防火墙放行 TCP `6233`，另一设备打开 `http://电脑的局域网IP:6233/`。不要填写 `0.0.0.0` 或 `127.0.0.1`。

## 连不上时检查

1. 本机 Pi Desk 能否打开，电脑和桌面端是否仍在运行。
2. 隧道地址、连接密钥是否正确，公网端口是否已连接。
3. 服务器是否放行 `7001`、`7002` 和实际使用的公网端口，访问地址是否写对。

忘记访问密码时，查看[密码恢复方法](/docs/faq/#忘记登录密码)。
