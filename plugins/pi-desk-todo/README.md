# @jetcrab/pi-desk-todo

在 Pi Desk 输入框上方展示当前工作的实际进度，支持二级任务、并行和阻塞。Todo 不是开发计划或执行依据，应随实际情况调整。

模型调用 `todo` 工具，每次提交完整内容，替换当前展示：

```json
{
  "title": "接口迁移",
  "items": [
    { "id": "review", "title": "核对接口", "status": 2 },
    { "id": "verify", "title": "验证调用", "status": 1 }
  ]
}
```

状态：`0` 待开始、`1` 进行中、`2` 已完成、`3` 受阻；受阻须提供 `note`。父阶段使用 `{ id, title, children }`，不传状态；子任务使用上述叶子结构。全树 ID 唯一，最多100个节点、64KiB。

悬停或聚焦摘要查看完整任务树，点击保持展开；更新提示约4秒后收起。右侧 × 同步隐藏当前会话的展示，内容仍在服务端会话内存中；再次登记会替换并重新显示。

不保存可恢复Todo快照，不从聊天历史恢复；会话运行态重启、重载或Pi树导航后为空。普通工具调用参数仍可能存在于Pi聊天历史中。

同时提供原生Pi扩展与Pi Desk界面。界面需要支持 `registerWidget` 与SDK `PluginPopover` 的宿主；纯Pi模式仍可登记进度，但没有网页挂件。不要同时启用另一个同名 `todo` 工具。
