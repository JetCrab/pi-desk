手机、平板或另一台电脑都能访问同一个 Pi Desk 工作台。项目和任务仍在原来的电脑上运行，远程设备只是打开它的网页。

## 先准备公网入口

用于公网访问的设备需已安装 Docker。Docker Desktop 需先在设置中启用[主机网络](https://docs.docker.com/engine/network/drivers/host/)。执行下方命令，控制服务和中继共用一个服务入口。

```bash
docker run -d --name pi-desk-tunnel --pull=always --network host --restart=always --log-opt max-size=10m --log-opt max-file=3 -v pi-desk-tunnel-data:/data ghcr.io/jetcrab/pi-desk-tunnel:latest
```

首次启动自动生成 64 位十六进制控制密钥（32 个随机字节），保存在命名卷的 `/data/server-key`。读取密钥：

```bash
docker exec pi-desk-tunnel cat /data/server-key
```

重启或重建容器时复用 `pi-desk-tunnel-data` 卷，控制密钥保持不变。需要自行指定密钥时，可在启动命令中额外加入 `-e PI_DESK_TUNNEL_SERVER_KEY='<64位十六进制密钥>'`；显式值优先，并更新卷中的控制密钥。

部署详情见[隧道部署说明](https://github.com/JetCrab/pi-desk/tree/main/apps/tunnel#部署网关与-relay)。

## 设置密码与桌面连接

<!-- devices-demo -->

1. 在运行 Pi Desk 的电脑上，打开工作台「设置 → 登录保护」。设置密码并点击「启用登录保护」；可用「生成密码」。密码须为 12–64 个字符，包含大写、小写、数字、符号中的至少三类。保存后，所有设备需重新登录。
2. 打开桌面「控制中心 → 远程访问 → 设置」，在「服务器设置」填写服务端地址 `http://服务器IP:7001` 和上述控制密钥，点击「保存设置」。控制和中继使用该 URL 的同一入口，不另填中继地址；这里不是手机要打开的网页地址。
3. 在「本机共享 → 共享端口」填写 Pi Desk 的本机端口，开启公网访问，填写业务端口，点击「开始共享」。
4. 等待显示「共享中」，复制公网链接或地址。在手机浏览器打开该地址，或将网址填入 Android 客户端，再用第 1 步的密码登录。公网地址由桌面填写的服务端 URL 主机和业务端口生成；手机不需要控制密钥。发送一条消息，确认回复能实时出现。

共享端口与桌面已配置的本机 HTTP(S) 网址匹配时，才提供「打开网页／复制公网链接」；普通 TCP 端口只提供地址。端口按实际配置填写，演示中的地址不能访问。

## 保持可用与安全

- Pi Desk 服务和提供端桌面应用需保持运行。
- 访问密码用于登录工作台，控制密钥用于桌面连接隧道，不要发给普通网页访问者。
- 隧道数据端到端加密，HTTP 中继准入令牌和浏览器 HTTP 访问本身不加密。
- 修改服务器地址或密钥后，退出并重启桌面应用。

## 连不上时检查

1. 先确认电脑上的 Pi Desk 网页能打开，桌面共享项已显示「共享中」。
2. 核对服务器地址和控制密钥；修改连接设置后重启桌面应用。
3. 从共享项的「连接详情」查看错误。仅容器运行或健康检查成功不代表转发已可用。

忘记访问密码时，查看[密码恢复方法](/docs/faq/#忘记登录密码)。
