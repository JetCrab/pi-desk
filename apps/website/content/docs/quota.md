额度查看把已配置服务返回的余额和额度窗口集中展示，方便判断还能使用多少、何时重置。它查询对应服务，不用历史会话 Token 推算余额；百分比、金额和重置时间各有含义，不能混着读。

## 先分清四层信息

**渠道**负责连接服务，**来源**是你保存的一组配置。每个来源按**账号**展示，账号内的**额度项**表示周期、余额或模型额度。同一种额度类型使用相同布局，不因接入渠道不同而变化；不同来源的同名账号不会合并。

<!-- quota-principle -->

目前支持 OpenRouter、Moonshot / Kimi API、SiliconFlow、智谱 Coding Plan、OpenCode Go、CommandCode、CPA 和 Antigravity Manager。CPA 一次配置即可查询其中的 Codex、Devin 账号；其他账号类型会显示状态和暂不支持的提示。各渠道需要对应的管理权限、查询凭据或套餐。

当前实现没有 Windows 专属限制。请求由运行 Pi Desk 的电脑发出，这台电脑必须能访问对应服务，手机只负责查看界面。

## 先配置，再查看查询结果

先[安装插件](/docs/plugins/#下载安装) `@jetcrab/pi-desk-quota-viewer`，按提示加载。从左侧底部“设置”进入 **插件设置 → 额度设置**，选择“额度来源”，点击“添加来源”。

下面使用真实支持的 **OpenCode Go** 渠道介绍表单，来源名“轻舟项目”是虚构示例，API Key 只有明显占位符。全部保存、数值和失败状态均为示意，不会连接真实服务。

<!-- quota-demo -->

1. **选择渠道并填写来源**：选择 OpenCode Go，修改“显示名称”，勾选“启用来源”，填入该套餐的 API Key。
2. **保存配置**：点击“保存全部更改”。新启用来源会发起查询，但保存成功只说明配置已保存，不证明认证或服务查询成功。
3. **打开额度应用**：关闭设置，在左侧快捷区点击“额度”，打开“额度查看器”；手机先展开侧栏，入口较多时在快捷区“更多”中找。
4. **查看账号额度**：本例返回 5 小时、周、月额度百分比。主行用紧凑额度条展示名称、剩余量和重置倒计时。有补充信息时才提供“详情”，展开查看快照时间、额外额度或余额明细；不会重复铺开主行已显示的数值。Codex 的重置次数直接显示在套餐右侧，例如“剩余重置1”。

## 配置与显示怎么调整

<!-- quota-config -->

OpenCode Go 需要有效的对应套餐，其他渠道字段会不同。例如 OpenRouter 的 Management Key 读取账户 Credits，API Key 读取当前 Key 额度，至少填一项，不能互相替代。

选择 **CPA**，填写 Management URL 与 Management Key。插件自动发现账号，分别查询 Codex 和 Devin 的额度；停用、失败和暂不支持的账号仍显示状态。旧 Codex／Devin 来源自动兼容；同一管理地址和密钥的旧来源合并，不需要重复填写。Codex 倒计时有天数时同时保留小时，例如 `3d0h`；不足一天仍显示小时、分钟。Devin 查询要求 CPA 支持请求正文中的 Token 替换。

选择 **Antigravity Manager**，填写管理地址和管理后台密码。插件读取管理器保存的 Google 账号额度快照：有分组时按返回的额度组和周期展示，没有分组时按模型展示；不会把相同百分比的模型猜成共享池。暂停代理的账号仍可查看已有额度。

在“显示设置”中，重置时间可选“倒计时”或“具体时间”。应用里可按渠道筛选并搜索账号。“显示项”按额度类型组织，同类型的不同来源共享显示偏好；隐藏只改变展示，不停用查询。主行保持账号和核心额度，辅助内容按需展开。

## 刷新与结果边界

- **不是定时轮询。** 没有通用自动刷新开关或可编辑刷新间隔。打开应用会查询，结果返回后自动更新；重连可复用缓存，需要重查时点击“刷新”，仍受最小请求间隔和服务限流约束。
- **Manager 刷新只重新读取快照。** 不触发管理器的额度刷新、OAuth 刷新、账号切换或预热。快照更新仍由管理器负责；详情中的时间是快照时间，不保证每个额度桶都在该时刻重新观测。
- **失败不代表额度为零。** 查询失败可能保留旧结果与旧快照时间。主行提示异常，详情说明原因；没有取得数据时不显示零额度。
- **按状态与单位读数。** “未知”不能当零，“无限”表示无上限，“—”表示不适用。没有重置时间就不要自行推算；百分比也不等于剩余金额或可用 Token 数。
