插件让 Pi Desk 按需增加功能：给 AI 新工具，也能给你增加页面和面板。不用一次装齐，选自己需要的即可。

## 下载安装

1. 打开“设置 → 插件”，展开“安装插件”。
2. 在“插件来源”填入 npm 包名，例如 `npm:@jetcrab/pi-desk-usage`，点击“安装”并确认。
3. 等待安装完成，按提示加载或重启，再打开插件入口。

插件会从 npm 下载到运行 Pi Desk 的电脑，不用手动解压。也可以填写 Git 地址或本地插件目录，或者直接让 AI 帮你安装。

## 官方插件

下表包名均以 `@jetcrab/` 为前缀。

| 插件与包名                               | 能做什么                                          |
| ---------------------------------------- | ------------------------------------------------- |
| **后台任务** · `pi-desk-bg-run`          | 后台运行命令，在任务中心看日志、停止任务          |
| **子代理** · `pi-desk-subagent`          | 将独立任务交给不同代理，查看各自执行过程          |
| **交付物** · `pi-desk-deliverables`      | 将完成的图片、页面、报告集中到会话侧栏预览        |
| **模型用量** · `pi-desk-usage`           | 查看模型使用量、费用和单个会话的消耗              |
| **上下文管理** · `pi-desk-ctx`           | 减少旧工具过程占用，保留结论和历史回查            |
| **额度查看** · `pi-desk-quota-viewer`    | 集中查看已配置模型服务的余额与剩余额度            |
| **Tibo 动态** · `pi-desk-tibo-monitor`   | 跟踪 Tibo 动态、翻译内容，提示 Codex 额度重置消息 |
| **工具调用理由** · `pi-desk-tool-reason` | 让 AI 在文件和命令工具调用中说明目的              |
| **远程调试** · `pi-desk-remote-debug`    | 将本机开发页面临时开放给其他设备测试              |

额度和动态等插件需先在对应设置页完成配置。远程调试当前需要 Windows x64 和已配置的[桌面隧道](/docs/devices/#配置桌面端)，它用于测试项目，不是远程访问 Pi Desk。

## 更新与加载

- **更新已安装插件**：在插件管理中点击“检查插件更新”，有新版本时再确认更新。
- **加载本地修改**：代码修改并构建后，点击“加载变更”，或在插件详情中“重新加载”。
- **更新聊天工具**：在会话空闲时点击“更多 → 重载 Pi 配置”；只更新界面通常不需要这一步。提示需要重启时，按提示操作。

想做自己的功能？看[让 AI 开发插件](/docs/development/)。
