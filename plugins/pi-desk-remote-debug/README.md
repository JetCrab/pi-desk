# Pi Desk — pi-desk-remote-debug

包名：`@jetcrab/pi-desk-remote-debug`。插件接口以源码导出为准，个人配置不随包分发。

官方说明：[使用说明](https://pidesk.dev/docs/remote-debug/)

公网调试需要由同机 Pi Desk 桌面端托管服务，并在桌面“隧道 → 连接设置”中保存控制服务地址和密钥。插件不附带或自动下载独立隧道程序；未由桌面端托管时，公网调试不可用。

本地入口就绪后即可访问，端口登记、Gateway 和公网隧道在后台准备。公网端口被占用、未由桌面端托管、隧道连接失败或运行后退出，均不停止本地项目；错误可在运行详情与日志查看。本地项目只在显式停止、插件关闭或项目命令退出时结束。

插件调用同机桌面程序的 `--tunnel-client --stats`，每次调试使用独立临时提供端身份，不复用桌面提供端私钥，也不修改桌面发布表。项目 `.pi/remote_debug.yaml` 的端口和路由格式不变；公网访问仍由普通浏览器或 TCP 程序直接访问 `host:port`，不要求访问者安装隧道客户端。

使用支持客户端映射的桌面和宿主时，在另一台电脑的桌面工作台打开远程调试，运行就绪后会自动建立本地映射；“本地”行显示当前电脑的回环地址及实际“直连／中继”标签。映射经过调试 Gateway，保留 HTTP/WebSocket 路由；连接失败不影响下面的公网地址。两端需使用相同隧道控制服务并配置有效密钥。localhost／回环工作台不创建映射；普通浏览器及旧宿主保持原访问方式。关闭调试弹窗保留连接，停止调试、释放页面或退出客户端时清理。

日志中的“活动 TCP”是当前业务转发流数量，不是请求数或人数；公网入口的 direct/relay 仅表示网关到提供端的实际内层路径。连接统计只属于当前调试 CLI，不并入桌面本进程统计。

使用该插件前，桌面端须支持 `--stats`，并与隧道服务端同步使用 v2 协议；不支持时会提示升级，不静默移除统计参数或降级到旧 Noise 协议。升级在维护窗口进行，活动 TCP 会断开；回退使用备份的旧制品与配置。部署及 CLI 合同见[隧道手册](../../apps/tunnel/README.md)。

启动或重启时，若本机端口已被占用，会列出端口、进程名和 PID，询问是否强制结束并继续启动；取消不影响原服务。确认后重新核对占用者，变化时需再次确认。无法识别占用者、系统或 Pi Desk 自身占用时不提供强杀；其他活动调试任务占用的本机端口仍需手动处理。macOS/Linux 的进程查询需要系统提供 `lsof`。
