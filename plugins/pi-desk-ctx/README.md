# Pi Desk — pi-desk-ctx

包名：`@jetcrab/pi-desk-ctx`。插件接口以源码导出为准，个人配置不随包分发。

官方说明：[使用说明](https://pidesk.dev/docs/context/)

## 图片整理

在“上下文忽略”设置页单独启用图片整理，默认关闭，与 token 自动忽略开关独立。默认图片发送量超过 24 MiB 时触发，目标为 12 MiB，同时保留最近 12 个有效助手轮与最近 3 个带正文助手轮的交集；四个数值均可调整。旧配置未包含图片设置时保持关闭。

每次模型上下文转换先应用已有过程忽略，再统计剩余图片的 base64 字节数；这不是完整 HTTP 请求体大小，也不是 token 数。超限时从旧到新按轮次整组替换图片为文字占位，文字、工具身份、原始会话和磁盘文件不变，不降低图片质量。两次请求间恢复或切换分支时按当前上下文重算，不持久化图片裁剪状态。

有效助手轮必须包含正文或工具调用且正常完成；正文轮不含内部思考。错误、取消、未完成及空回应不计入。尚未经过有效助手回应的新图组不会拆分：自身不超过触发值时可高于整理目标；自身超过触发值时取消本次发送，并提示缩图或分批。旧图需要再次查看时重新读取或提供。

设置保存在 Pi AgentDir 的 `pi-desk-ctx.json`，新增 `imageBudget: { enabled, triggerBytes, targetBytes, keepAssistantTurns, keepTextTurns }`。字节值是 1–1 GiB 的整数且目标不大于触发值，轮数为 1–100。关闭后保留填写值；原生会话在下一次开始任务时重新读取设置，升级插件后已有会话须重载 Pi 配置。
