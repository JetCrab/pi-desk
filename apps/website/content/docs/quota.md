额度查看把已配置服务返回的余额和额度窗口集中展示，方便判断还能使用多少、何时重置。它查询对应服务，不用历史会话 Token 推算余额；百分比、金额和重置时间各有含义，不能混着读。

## 先分清四层信息

**渠道**是服务类型，**来源**是你保存的一组配置。服务能返回账号时按**账户**展示，否则使用来源名；每条记录下的**额度窗口**表示具体周期或额度项，一个来源可能返回多个窗口或账户。

<!-- quota-principle -->

目前支持 OpenRouter、Moonshot / Kimi API、SiliconFlow、智谱 Coding Plan、OpenCode Go、CommandCode、Codex（通过 CPA）和 Devin（通过 CPA）。不是所有模型服务都支持；Codex、Devin 来源需 CPA 管理端，各渠道也需要对应的查询权限或套餐。

当前实现没有 Windows 专属限制。请求由运行 Pi Desk 的电脑发出，这台电脑必须能访问对应服务，手机只负责查看界面。

## 先配置，再查看查询结果

先[安装插件](/docs/plugins/#下载安装) `@jetcrab/pi-desk-quota-viewer`，按提示加载。从左侧底部“设置”进入 **插件设置 → 额度设置**，选择“额度来源”，点击“添加来源”。

下面使用真实支持的 **OpenCode Go** 渠道介绍表单，来源名“轻舟项目”是虚构示例，API Key 只有明显占位符。全部保存、数值和失败状态均为示意，不会连接真实服务。

<!-- quota-demo -->

1. **选择渠道并填写来源**：选择 OpenCode Go，修改“显示名称”，勾选“启用来源”，填入该套餐的 API Key。
2. **保存配置**：点击“保存全部更改”。新启用来源会发起查询，但保存成功只说明配置已保存，不证明认证或服务查询成功。
3. **打开额度应用**：关闭设置，在左侧快捷区点击“额度”，打开“额度查看器”；手机先展开侧栏，入口较多时在快捷区“更多”中找。
4. **查看窗口详情**：本例返回 5 小时、周、月额度百分比。点击“详情”查看已用、剩余、窗口和服务给出的重置时间，不是把账户余额当成每个窗口的限额。

## 配置与显示怎么调整

<!-- quota-config -->

OpenCode Go 需要有效的对应套餐，其他渠道字段会不同。例如 OpenRouter 的 Management Key 读取账户 Credits，API Key 读取当前 Key 额度，至少填一项，不能互相替代。

Devin 选择 **Devin（通过 CPA）**，填写 CPA 的 Management URL 与 Management Key；插件自动查询其中启用的 Devin 账号，显示每日、每周剩余百分比、重置时间和返回的套餐名称，不推算金额或 ACU。CPA 后端需支持请求正文中的 Token 替换；现有 Codex 渠道能用，不代表旧版后端一定支持 Devin 查询。

在“显示设置”中，重置时间可选“倒计时”或“具体时间”。应用里可搜索渠道、来源或账号，按渠道筛选，用“显示项”隐藏暂时不看的额度；隐藏只改变展示，不停用来源。

## 刷新与结果边界

- **不是定时轮询。** 没有通用自动刷新开关或可编辑刷新间隔。打开应用会查询，结果返回后自动更新；重连可复用缓存，需要重查时点击“刷新”，仍受最小请求间隔和服务限流约束。
- **失败不代表额度为零。** 查询失败可能保留旧结果，关注“来源异常”“已过期”和数据更新时间；没有取得数据时，按未取得数据处理。
- **按状态与单位读数。** “未知”不能当零，“无限”表示无上限，“—”表示不适用。没有重置时间就不要自行推算；百分比也不等于剩余金额或可用 Token 数。
