# Pi Desk — pi-desk-tibo-monitor

包名：`@jetcrab/pi-desk-tibo-monitor`。插件接口以源码导出为准，个人配置不随包分发。

官方说明：[使用说明](https://pidesk.dev/docs/tibo/)

设置页面首次直接显示翻译模型、检查间隔和保留条数；选择可用模型后“开始监听”保存并启用。已有配置或历史时进入动态阅读，通过“设置”编辑；保存或取消后返回阅读。检查间隔为 30–86400 秒整数，保留动态为 10–200 条整数，均直接展示。监听、翻译与模型错误保留在对应位置，不会以空态替代失败信息。
