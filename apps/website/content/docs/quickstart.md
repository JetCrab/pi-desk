Pi Desk 复用 Pi 的模型配置和登录信息，已有可用模型无需重新添加。配置方式见 [Pi 官方模型文档](https://pi.dev/docs/latest/models)。

## 1. 配置模型

在电脑上打开 Pi Desk：

1. 打开“设置 → 模型 → 模型管理”。
2. 点击“添加服务连接”，填写服务 ID（例如 `my-provider`）、服务商提供的服务地址、访问密钥和默认调用方式，点击“应用到草稿”。
3. 点击右上角“刷新模型目录”，获取最新模型资料。
4. 点击服务下的“＋”添加模型，在“模型 ID”中搜索，选择对应模型的配置，自动填入模型名称、容量和价格等参数。
5. 点击底部“保存模型配置”。

模型 ID 和调用方式以服务商提供的信息为准。

## 2. 选择项目并创建会话

点击侧栏的“新建工作会话”，选择项目目录。没有列出的目录，点击“选择其他目录”，再点“选择当前目录”。

目录要在运行 Pi Desk 的电脑上已经存在。

## 3. 选择模型并开始对话

1. 点击聊天输入区的模型名称，在“全部模型”中选择服务和模型。
2. 发送一条消息，让 AI 查看项目目录并介绍主要文件。
3. 收到回复，就完成了第一次对话。

模型未出现时，检查配置是否保存、访问密钥是否有效。其他问题见[常见问题](/docs/faq/)。
