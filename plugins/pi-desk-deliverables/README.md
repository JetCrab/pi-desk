# Pi Desk — pi-desk-deliverables

包名：`@jetcrab/pi-desk-deliverables`。插件接口以源码导出为准，个人配置不随包分发。

`deliverable.items[].path` 支持绝对路径或相对当前会话 cwd 的路径（包括 `../`），文件可以位于项目外。登记时校验文件存在且为普通文件；项目内文件保存为 `/` 分隔的相对路径，项目外文件保存为绝对路径。已有相对路径交付记录仍可读取。

项目外文件的预览、图片组浏览与“打开所在文件夹”需要支持绝对文件路径的 Pi Desk 宿主；仅更新插件不能解除旧宿主的路径限制。
