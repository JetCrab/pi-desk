# Pi Desk — pi-desk-deliverables

包名：`@jetcrab/pi-desk-deliverables`。插件接口以源码导出为准，个人配置不随包分发。

官方说明：[使用说明](https://pidesk.dev/docs/deliverables/)

`deliverable.items[].path` 支持已存在的普通文件或文件夹，可使用绝对路径或相对当前会话 cwd 的路径（包括 `../`）。项目内路径保存为 `/` 分隔的相对路径，当前目录保存为 `.`，项目外路径保存为绝对路径；类型由登记工具识别，无需额外传参。已有交付记录仍按文件读取。

点击文件保持独立文件预览；点击文件夹使用宿主项目预览，以该目录为根浏览当前文件，不改变会话 cwd。文件夹只登记路径，不递归登记内容或复制备份。目录条目的右键菜单提供“复制地址”，文件条目另有“打开所在文件夹”。

项目外文件的预览、图片组浏览与“打开所在文件夹”需要支持绝对文件路径的 Pi Desk 宿主；仅更新插件不能解除旧宿主的路径限制。

侧栏顶部右侧提供“刷新交付物”，重新读取当前会话分支的最新列表；读取期间显示忙碌并禁用按钮。支持顶部操作的宿主会显示此入口，旧宿主仍可查看交付物列表，并在重新打开 Tab 时读取最新数据。
