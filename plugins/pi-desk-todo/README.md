# @jetcrab/pi-desk-todo

在 Pi Desk 输入框上方展示当前工作的实际进度，使用单层任务列表，支持并行和阻塞。Todo 不是开发计划或执行依据，应随实际情况调整。

模型调用 `todo` 工具，每次提交完整内容，替换当前展示：

```json
{
  "title": "接口迁移",
  "items": [
    { "id": "review", "title": "核对接口", "status": 2 },
    { "id": "verify", "title": "验证调用", "status": 1 }
  ]
}
```

每项使用 `{ id, title, status, note? }`，不支持嵌套。状态：`0` 待开始、`1` 进行中、`2` 已完成、`3` 受阻；受阻须提供 `note`。列表内 ID 唯一，最多100个任务、64KiB。

进度使用横向摘要与分段进度条展示，保留完成、受阻等状态色。会话切换时直接恢复展示，不播放入场动效；只有详情浮层展开／收起使用局部动效，不增加聊天区域占位。进度变化时更新摘要、计数和已展开的任务列表，不自动弹出提示。鼠标在摘要上连续悬停 500ms 后查看完整任务列表，提前移走则取消展开；键盘聚焦立即查看，点击立即展开并保持。右侧 × 同步隐藏当前会话的展示，内容仍在服务端会话内存中；再次登记会替换并重新显示。明暗主题、文字放大与减少动态效果设置沿用宿主。

仅更新界面不会更新已有会话的工具参数；会话加载新 Native 代码后才使用单层参数。旧会话返回的二级快照在界面中摊平显示。

旧会话未加载 Todo 查询方法时，挂件静默隐藏，不显示同步错误，也不自动重载会话；方法可用后，通过后续进度通知或连接恢复重新同步。

不保存可恢复Todo快照，不从聊天历史恢复；会话运行态重启、重载或Pi树导航后为空。普通工具调用参数仍可能存在于Pi聊天历史中。

同时提供原生Pi扩展与Pi Desk界面。界面需要支持 `registerWidget` 与 SDK `PluginPopover` 的宿主；纯Pi模式仍可登记进度，但没有网页挂件。不要同时启用另一个同名 `todo` 工具。
