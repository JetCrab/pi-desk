# Source attribution

This plugin is maintained in [`plugins/pi-desk-remote-debug/`](https://github.com/JetCrab/pi-desk/tree/main/plugins/pi-desk-remote-debug) and licensed under Apache-2.0.

The package contains Node.js plugin code and does not bundle a native Tunnel Client. Public tunneling uses the headless capability provided by the Pi Desk desktop application on the same machine. Native tunnel source and its third-party notices belong to the desktop application, not this plugin package.
